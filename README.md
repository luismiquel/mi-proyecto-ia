# 🚀 LifeOS - IA Automation & GHL Expert Tool

**Una PWA (Progressive Web App) 100% local, privada y diseñada para el cierre de ventas y gestión de consultoría de IA.**

---

## ¿Por qué Local-First?

LifeOS está construido con una arquitectura **Local-First** para proteger la información más sensible de tu operación:

- Los datos de clientes se almacenan en el dispositivo.
- Las proyecciones del ROI se calculan en local.
- No depende de servidores externos para funcionar.

✅ Resultado: **privacidad total**, mayor control operativo y una experiencia profesional incluso sin conexión a internet.

---

## Módulos Clave

- 📈 **Calculador de ROI Pro**  
  Para proyecciones financieras en vivo con clientes y soporte de cierre comercial.

- 🤝 **CRM de Dropservicing**  
  Seguimiento de prospectos, estados comerciales y gestión de oportunidades sin fugas de datos.

- 🧠 **Prompt Library**  
  Acceso rápido a prompts maestros de GHL y scripts de venta listos para copiar y usar.

- 📅 **Dashboard "Hoy"**  
  Organización diaria con parser inteligente para capturar tareas en lenguaje natural.

## Instalación (móvil + GitHub Pages)

1. Sube el repositorio a GitHub.
2. Activa **GitHub Pages** en:
   - `Settings` → `Pages`
   - Source: `Deploy from a branch`
   - Selecciona tu rama principal y `/root`.
3. Abre la URL publicada de GitHub Pages desde tu móvil.
4. Añade la app a inicio:
   - **iOS (Safari):** Compartir → **Añadir a pantalla de inicio**.
   - **Android (Chrome):** Menú → **Instalar app** / **Añadir a pantalla de inicio**.
